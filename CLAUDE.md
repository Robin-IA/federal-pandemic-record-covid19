# federal-pandemic-record-covid19

**Develop at `Robin-IA/federal-pandemic-record-covid19`; `internetarchivecanada`
is the mirror.** In a checkout, `origin` is Robin-IA and `canada` is the mirror.

- Branch, push and open pull requests against `origin` only:
  `gh pr create --repo Robin-IA/federal-pandemic-record-covid19 --base main`.
- Never commit to, branch on, or open a pull request against `canada`.
- After a merge to `origin/main`, update the mirror with `git push canada main`.
  That push is what publishes the explorer, through the mirror's GitHub Pages.
- Merging is Robin's call.

See [README.md](README.md) and [PICKUP.md](PICKUP.md).
